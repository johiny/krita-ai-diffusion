# MiniMax H3 masked inpaint (selection edits that leave the rest untouched)

> **For Hermes:** implement task by task with TDD; deploy to Krita before pushing.

**Goal:** replace the H3 selection path (crop → regenerate → paste) with a latent-masked sample, so that outside the selection the canvas comes back unchanged, the way Qwen 2.1 does it.

**Architecture:** one small server-side node plus the plugin change. `MiniMaxH3ImageConditioning` returns an *empty* latent and injects the source as a reference latent, so a noise mask alone can't preserve anything. The fix is to seed the sampler with a **VAE-encoded latent of the canvas** and attach the mask with `SetLatentNoiseMask`; `KSamplerX0Inpaint` in `comfy/samplers.py:630` then pins every step's output outside the mask to that latent, model-agnostically.

One caveat found on the way: the **audio/video checkpoints (every video finetune: ErosMax, DaSiWa) read `x[1]` as the audio stream** (`comfy/ldm/minimax/model.py:677`) and crash with `IndexError` on the plain tensor `VAEEncode` returns. `MiniMaxH3AV.fix_empty_latent` builds `NestedTensor((video, zeros_audio))` but is only called for empty latents, so `custom_nodes/comfyui-h3-masked-latent` wraps a real latent the same way, and is a no-op for the one-frame image checkpoints.

**Tech stack:** ComfyUI nodes `VAEEncode`, `SetLatentNoiseMask`, `SamplerCustomAdvanced`, `H3LatentForModel` (local pack); plugin builders `vae_encode`, `set_latent_noise_mask`, `stabilize_mask`.

## Feasibility: proven on the rig (2026-11-13, 1024×1024, official pruned int8 + TE 32B, 6 steps euler/simple, CFG 1)

Spike graph: `LoadImage → VAEEncode → SetLatentNoiseMask → SamplerCustomAdvanced → VAEDecode`.

| region | mean abs diff vs source | pixels changed >2 |
|---|---|---|
| inside the mask | 59.2 | 56.0 % |
| outside, 0–16 px ring | 48.3 | 49.2 % |
| outside, 16–32 px | 1.80 | 12.9 % |
| outside, >128 px | 1.66 | 7.3 % |

- The edit lands (a red balloon appeared in the masked sky) and the rest of the scene is coherent — no seams, no shift.
- Latent shapes line up: `VAEEncode` output is accepted by `SamplerCustomAdvanced` next to the H3 conditioning, no reshape node needed.
- The untouched area is **not** bit-exact: it goes through the H3 image VAE (16× downscale, 24 channels), which costs ~1.7/255 mean and moves ~7 % of pixels by more than 2 levels. Acceptable, and the same class of cost Qwen's VAE has.
- The mask boundary is quantised to the 16 px latent grid: the 0–16 px ring outside the mask changes by ~49 %. Any compositing feather must be **≥16 px**, so the plugin keeps an `apply_mask` pass over the original.

Compared with today's path on the same canvas (job 726b3417): the crop→paste chain moved content **40 px down** inside the selection, with a hard seam at the selection border.

## Current code to replace

`ai_diffusion/backend/workflow.py` → `inpaint_h3()` (~line 1487) does:

1. `_mask_bounds` → `_h3_context_bounds` (selection + 25 % pad, clamped to the canvas).
2. `w.crop_image(in_image, context_bounds)`.
3. `_h3_edit_extent` → upscale by an integer factor (1–4×) to ≤4 MP.
4. Sample, decode, crop the selection out in edit space, scale down, `composite_image_masked` back into the canvas.
5. `apply_mask` with `denoise_to_compositing_mask`.

Steps 2–4 exist **only** because the conditioning latent was empty. The masked latent removes all of them.

```python
def inpaint_h3(w, images, checkpoint, cond, sampling, params, misc, models):
    """H3 has no masked sampler, but a latent seeded from the canvas plus a noise mask pins
    every pixel outside the selection, so only the selection is regenerated."""
    _h3_no_regions(cond)
    extent = ScaledExtent.from_input(images.extent)

    model, clip, vae = load_checkpoint_with_lora(w, checkpoint, models.all)

    in_image = w.load_image(ensure(images.initial_image))
    in_image = scale_to_initial(extent, w, in_image, models)
    in_mask = w.load_mask(ensure(images.hires_mask))
    inpaint_mask = apply_grow_feather(w, in_mask, params)
    inpaint_mask = scale_to_initial(extent, w, inpaint_mask, models, is_mask=True)
    inpaint_mask = w.stabilize_mask(inpaint_mask)

    # The conditioning latent is all zeros: seed the sampler from the canvas instead, or the
    # noise mask has nothing to preserve and the model re-composes the whole crop.
    latent = w.vae_encode(vae, in_image)
    latent = w.set_latent_noise_mask(latent, inpaint_mask)

    positive = cond.positive.prepare(w, cond.style_prompt)
    references = _h3_references(w, cond)
    if references:
        positive = _h3_prepend(w, positive, _h3_edit_guide())
    prompt, _ = _h3_prepare(w, clip.model, vae, positive, extent.initial, in_image, models, references)
    negative = _h3_negative(w, cond, clip, vae, extent.initial, sampling)
    out_latent = _h3_sample(w, model, prompt, negative, latent, sampling, extent.initial, models)
    out_image = vae_decode(w, vae, out_latent, checkpoint.tiled_vae)

    out_image = w.color_match(out_image, in_image, inpaint_mask, misc.color_match)
    out_image = w.scale_image(out_image, extent.target)
    out_image = w.nsfw_filter(out_image, sensitivity=misc.nsfw_filter)

    # The mask lives on a 1/16 latent grid, so the sampler's output bleeds ~16 px past the
    # selection; paste through the selection again so the ring outside it stays original.
    compositing_mask = w.crop_mask(in_mask, Bounds(0, 0, *extent.target))
    compositing_mask = denoise_to_compositing_mask(w, compositing_mask, params)
    if params.blend <= 0:
        compositing_mask = w.shrink_mask(compositing_mask, 8, 16)
    w.send_image(w.apply_mask(out_image, compositing_mask))
    return w
```

## Risks and open questions

1. **Off-distribution latent.** H3 is trained on empty latents + reference latents. Seeding a real latent is out of distribution, but `KSamplerX0Inpaint` forces the outside, so the model only sees "half-clean" input in the masked area. The spike looked clean; verify on a photo-like image, not just flat shapes.
2. **VAE round trip is lossy.** ~1.7/255 mean and ~7 % of pixels drifting by >2. If Johiny needs bit-exact outside, this cannot be fixed without a custom node that composites the **original pixels** back outside the mask (which is what the final `apply_mask` already does inside the plugin — the loss only shows if the mask/feather is wrong).
3. **16 px grid.** Feather must be ≥16 px; the plan forces a minimum. A very thin selection (a few px) will still bleed.
4. **High resolution VRAM.** The masked path no longer upscales to 4 MP, so it should be lighter, but the VAE encode of a 2048² canvas is a new peak. Measure before recommending 2048².
5. **Reference layers.** `minimax_refs` still come from the conditioning; the masked latent and the references coexist in the spike-less graph but were not tested together. Test one edit with a `<layer:…>` reference.
6. **`refine_region`** for H3 maps to `inpaint_h3`, so it inherits the change; no separate work.
7. **Fallback if the masked latent misbehaves at high res:** keep the crop path but make it exact and shrink the context pad — strictly worse, only a safety net.
