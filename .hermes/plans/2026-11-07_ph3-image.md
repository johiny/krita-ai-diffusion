# P-H3 Image support (text-to-image + edit)

Date: 2026-11-07
Branch: `ph3-image` (base `origin/main` = `828b70c`)

## Goal

Make `p-h3-image_w4a8.safetensors` (PrunaAI P-H3 Image, MiniMax-H3 architecture) usable in the
plugin: it must show up as an architecture, generate text-to-image, and work in edit mode by
feeding the current canvas into its conditioning node.

## Non-goals

- Masked inpaint, regional prompts, ControlNet/IP-Adapter, layered output. The
  `PH3ImageConditioning` node takes a prompt plus reference images and returns its own latent, so
  those pipelines do not apply. Requests that need them fail with a clear message instead of
  producing a wrong graph.
- Tiled refinement / upscale passes specific to P-H3.
- Bundling or downloading the model files; they are user-provided.

## Contract

### C1 - Detection
ComfyUI reports `base_model: "unknown"` for every MiniMax H3 file, so the filename decides:
any file whose name contains `h3` or `minimax` is `Arch.h3` ("MiniMax H3").

One architecture covers the whole family - the P-H3 Image distillation and its finetunes (DaSiWa,
ErosMax, ref2va) share text encoder, VAE, conditioning node and schedule, and all of them run the
image graph (verified live: t2i 512x512, no LoRA, coherent output). A separate entry per variant was
tried and discarded: it splits one architecture across two labels for no functional gain.

### C2 - Resources
| Kind | Id | Filename patterns |
|------|----|-------------------|
| text encoder | `minimax` | `p-h3-image_text_encoder`, `p_h3_image_text_encoder` |
| VAE | `default` (h3) | `p-h3-image_vae`, `p_h3_image_vae` |

Both are optional for installation checks: a missing file degrades to "style unavailable".
Diffusion resolution multiple is 32.

### C3 - Architecture flags
`supports_cfg = False`, `supports_edit = True`, `is_edit = False`, `supports_regions = False`,
`has_controlnet_inpaint = False`, `supports_alpha = False`, `text_encoders = ["minimax"]`.

### C4 - Text-to-image graph
```
UNETLoader(p-h3-image_w4a8) -> MiniMaxH3SigmaShift(1.0, 1.0)
CLIPLoader(text_encoder, type="minimax")
VAELoader(vae)
PH3ImageConditioning(clip, vae, prompt, width=extent.width, height=extent.height)  -> (cond, latent)
RepeatLatentBatch(latent, batch_count)                        (only when batch > 1)
BasicGuider(model, cond)
SamplerCustomAdvanced(noise=RandomNoise(seed), guider, sampler=KSamplerSelect("er_sde"),
                      sigmas=ManualSigmas(8-step distilled schedule), latent)
VAEDecode -> [nsfw filter] -> scale_to_target -> send
```
User sampler/scheduler/steps/cfg are **honoured** (the user asked for full freedom, even when a
combination degrades output). Recommended recipe, documented in `MINIMAX_H3.md`: `er_sde`, scheduler
`manual` (distilled 8-step sigmas), 8 steps, CFG 1.0. Scheduler `manual` -> `ManualSigmas`; any other
scheduler -> `BasicScheduler` with the configured step count. CFG > 1 adds a second
`PH3ImageConditioning` (empty/negative prompt) plus a `CFGGuider`. Unknown sampler names fall back to
`er_sde`. Measured: `dpmpp_2m + karras + 12` returns an abstract field, while `dpmpp_2m` with the
manual schedule stays coherent - the knobs are for exploration, not a quality guarantee.

### C5 - Edit graph
Same graph, but `PH3ImageConditioning` receives `images.image_1` = current canvas scaled to
`extent.initial`. The node prefixes the instruction with `Edit <Picture 1>. ` when needed. Strength
is ignored (full regeneration), masks are not supported.

### C6 - Routing
`WorkflowKind.generate` -> `generate_p_h3`; `WorkflowKind.refine` -> `refine_p_h3`;
`WorkflowKind.inpaint` -> `inpaint_p_h3`; `WorkflowKind.refine_region` raises a clear error (region
layers have no equivalent in this model).

### C6b - Selection support (masked edit)
The model cannot mask, so a selection is emulated the way edit models do it:

1. crop the input image to `params.target_bounds` (converted to the initial resolution),
2. run the edit graph with that crop as `images.image_1` and width/height of the crop,
3. color-match against the crop, resample to the target bounds when the initial resolution differs,
4. composite back through the feathered/grown selection mask (`ETN_ApplyMaskToImage`).

Batch is always 1 for masked edits.

### C7 - UI
Style list shows the architecture icon (falls back to a neutral one, no dedicated SVG yet). The
edit-mode toggle appears because `supports_edit` is true.
